## 为什么

Change 1.1 已完成数据层和项目目录基础，但当前页面仍是脚手架默认首页，尚不具备 ChatBot 的基础界面结构。Change 1.2 需要先建立可复用的聊天 UI 组件库和响应式布局，为后续会话管理、AI 流式输出和消息持久化提供前端承载层。

## 变更内容

- 创建应用级聊天布局骨架，包含侧边栏区域和主聊天区域。
- 实现会话列表的静态 UI 组件，为 Change 1.3 的真实会话数据接入预留 props。
- 实现消息列表和消息气泡组件，为 Change 1.4/1.5 的消息流和历史消息展示预留结构。
- 实现聊天输入框组件，支持基础输入、提交按钮和禁用状态。
- 建立基础 UI 原语组件，例如按钮、文本区域和空状态展示。
- 调整全局样式和 Tailwind theme token，形成法律 AI 助手的基础视觉风格。
- 实现桌面端双栏布局（固定宽度侧栏 + 可收起/展开），以及移动端默认主聊天区 + 左侧滑出会话抽屉的响应式布局。

## 能力范围

### 新增能力

- `chat-layout`: 定义 ChatBot 页面布局、侧边栏、主内容区和响应式行为。
- `chat-components`: 定义会话列表、消息列表、消息气泡和聊天输入框等聊天 UI 组件行为。
- `ui-foundation`: 定义基础 UI 原语、主题 token、空状态和可访问性基础要求。

### 修改能力

- 无。现有主 specs 只覆盖数据持久化和项目结构，本变更新增前端 UI 能力，不改变既有要求。

## 影响范围

- 影响代码：`app/page.tsx`、`app/globals.css`、`components/layout/`、`components/chat/`、`components/ui/`。
- 影响体验：首页将从默认 Next.js 模板替换为法律 AI 助手的聊天界面骨架。
- 依赖影响：默认优先使用现有 React、Next.js 和 Tailwind CSS；仅在实现确有必要时再评估新增轻量 UI 依赖。
- 系统影响：不涉及数据库迁移、API 路由、AI 服务调用或新的环境变量。
