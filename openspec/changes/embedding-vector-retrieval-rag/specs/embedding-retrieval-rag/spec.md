## ADDED Requirements

### Requirement: 可重放的切片向量化
系统 MUST 仅为来自已激活且质量可用切片集的切片生成 Embedding。系统 MUST 使用服务端配置的模型标识和维度，并以切片、模型与内容哈希保证幂等。系统 MUST 验证模型响应的维度；不匹配时不得持久化该向量。

#### Scenario: 为缺失向量的切片生成 Embedding
- **WHEN** 授权的受控任务处理一个已激活、质量可用且尚无当前模型向量的切片
- **THEN** 系统生成并保存带模型、维度和内容哈希的向量记录

#### Scenario: 重复执行相同向量化任务
- **WHEN** 相同切片、内容哈希和模型再次被处理
- **THEN** 系统复用已有 Embedding 或跳过该切片，且不产生重复模型调用或记录

#### Scenario: 拒绝维度不匹配的模型响应
- **WHEN** Embedding 服务返回的向量维度与受配置或记录的维度不一致
- **THEN** 系统记录可操作失败原因，且不写入不一致的向量

### Requirement: 可恢复的向量化任务状态
系统 MUST 记录向量化批次的状态、模型、目标范围、进度、重试次数和失败原因。系统 MUST 对暂时性失败进行有限重试，并使后续执行能够处理缺失或失败项而不重新生成已成功的向量。

#### Scenario: 批次部分失败后恢复
- **WHEN** 一个批次中部分切片的模型调用在重试上限后仍失败
- **THEN** 系统保留已成功的向量、将批次标记为部分完成或失败并记录失败项；后续运行可只重试缺失或失败项

### Requirement: 授权范围内的向量相似度检索
系统 MUST 在服务端身份和知识库授权范围内检索向量。检索 MUST 排除未激活、不合格、模型或维度不匹配的切片；可选知识库与分类筛选只能收窄已授权集合。系统 MUST 使用参数化查询并按距离稳定排序返回受限数量的结果。

#### Scenario: 检索私有知识库中的相关切片
- **WHEN** 已认证用户针对其有权访问的知识库提交检索问题
- **THEN** 系统返回相似度排序的可用切片，并提供文档标题、页码、结构定位、内容和分数

#### Scenario: 拒绝跨用户知识库检索
- **WHEN** 用户尝试以知识库 ID 或其他参数请求另一用户的私有知识库
- **THEN** 系统拒绝或返回无结果，且不泄露该知识库、文档、切片或向量是否存在

#### Scenario: 应用分类过滤
- **WHEN** 调用方在其可访问范围内提供文档分类过滤条件
- **THEN** 系统只在该分类的可用切片中计算并返回结果

### Requirement: 可追溯且有界的 RAG 上下文
系统 MUST 由服务端将检索结果组装为有明确来源标签的有限上下文。每个来源必须包含可用的文档标题、页码和结构定位；系统 MUST 限制结果数量及每段和总上下文长度。RAG 指令 MUST 要求模型依据提供资料回答、引用来源标签，并在资料不足时明确不确定性。

#### Scenario: 用来源增强聊天回答
- **WHEN** 受保护聊天请求获得一个或多个可用检索结果
- **THEN** 系统将带来源标签的有界证据包加入模型上下文，且模型输出可引用这些标签

#### Scenario: 未检索到充分资料
- **WHEN** 检索没有返回满足阈值的结果或结果不足以支持回答
- **THEN** 系统不伪造资料来源，并要求模型说明知识库中没有足够依据或按既定产品策略返回可区分结果

### Requirement: 聊天检索输入不信任客户端
系统 MUST 从已验证会话和服务端数据构建检索范围与聊天历史。客户端不得通过请求体提供被信任的向量、检索正文、知识库归属或来源标签。

#### Scenario: 忽略客户端伪造来源
- **WHEN** 客户端在聊天请求中附带检索内容、来源标签或他人知识库标识
- **THEN** 系统不将其作为 RAG 证据使用，并继续以服务端授权和检索结果决定上下文
