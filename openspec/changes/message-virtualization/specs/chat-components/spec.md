## ADDED Requirements

### Requirement: 消息列表虚拟滚动

`MessageList` SHALL 支持对长消息时间线进行虚拟化渲染，只挂载可视区域及少量 overscan 范围内的时间线项。

当消息数量较少时，系统 MAY 直接渲染全部消息，但必须保持与虚拟化路径一致的消息渲染器、滚动行为和交互回调。

#### Scenario: 长列表只渲染可见区域

- **WHEN** 当前会话包含超过虚拟化阈值的消息
- **THEN** DOM 中只存在可视区域及 overscan 范围内的消息项，滚动到其他位置时动态替换可见项

#### Scenario: 普通消息行为保持不变

- **WHEN** 虚拟化消息项为 user、assistant 或 system 消息
- **THEN** 系统继续使用现有角色样式、Markdown、复制、删除和重新生成功能

### Requirement: 动态消息高度测量

虚拟化消息列表 MUST 支持不固定高度的消息，并在 Markdown 渲染、代码高亮、展开折叠或流式内容变化后更新对应项高度。

#### Scenario: Markdown 渲染后高度变化

- **WHEN** assistant 消息从流式纯文本切换为 Markdown 渲染
- **THEN** 虚拟列表重新测量该消息，并保持后续消息的可见位置稳定

#### Scenario: 长内容展开后高度变化

- **WHEN** 用户展开折叠的日志、JSON 或代码结果
- **THEN** 只重新测量该时间线项，列表不发生整页跳动

### Requirement: 虚拟列表流式滚动

消息列表 MUST 保留现有 stick-to-bottom 规则，并兼容虚拟化定位。

#### Scenario: 底部附近接收流式内容

- **WHEN** 用户距离底部不超过 80px，且最后一条 assistant 消息持续接收 token
- **THEN** 列表在帧级别合并更新并跟随最后一项，且不显示「回到底部」按钮

#### Scenario: 用户向上阅读时接收流式内容

- **WHEN** 用户已离开底部附近，且 assistant 消息继续流式增长
- **THEN** 列表不得强制滚动，用户当前阅读位置保持不变，并显示「回到底部」按钮

#### Scenario: 发送消息后恢复到底部跟随

- **WHEN** 用户发送新消息或点击「回到底部」
- **THEN** 列表定位到最后一项并恢复后续流式内容的自动跟随

### Requirement: 历史消息加载位置保持

当系统在列表顶部加载更早的历史消息时，MUST 保持加载前第一条可见消息及其相对视口位置。

#### Scenario: 向上加载历史

- **WHEN** 用户滚动到历史列表顶部并触发更早消息加载
- **THEN** 新消息插入顶部后，用户仍停留在原先阅读的消息附近，不发生明显跳动

#### Scenario: 底部状态下追加新消息

- **WHEN** 用户处于底部跟随状态且收到新消息
- **THEN** 新消息出现在列表底部，列表继续跟随到底部

### Requirement: 长内容折叠与懒加载

超长日志、JSON、代码结果和未来工具结果 MUST 支持摘要优先、详情按需展开的展示策略。

#### Scenario: 长工具结果默认折叠

- **WHEN** 时间线项包含超过展示阈值的工具结果或日志
- **THEN** 默认展示状态、摘要和展开入口，不立即渲染全部详情

#### Scenario: 用户展开详情

- **WHEN** 用户点击长结果的展开入口
- **THEN** 展示完整内容并重新测量该项高度，其他消息状态不受影响

### Requirement: Agent 时间线扩展点

消息列表 SHALL 提供可扩展的时间线项渲染接口，以支持未来的工具调用、工具结果和执行状态；本 Change 不要求实现 Agent 执行逻辑。

#### Scenario: 渲染执行状态项

- **WHEN** 时间线收到一个可识别的执行状态项
- **THEN** 使用独立的状态展示组件渲染，而不是强制转换为普通 assistant Markdown 消息

#### Scenario: 未知时间线项安全降级

- **WHEN** 时间线收到当前版本无法识别的扩展项
- **THEN** 展示可理解的降级摘要，不阻塞其他消息渲染

### Requirement: 对话列表范围边界

本 Change 不要求左侧 `ConversationList` 使用虚拟滚动；其普通滚动、选择、删除和空状态行为 MUST 保持不变。

#### Scenario: 会话侧栏正常滚动

- **WHEN** 用户滚动左侧会话列表
- **THEN** 会话选择、删除和当前项高亮行为与本 Change 前一致
