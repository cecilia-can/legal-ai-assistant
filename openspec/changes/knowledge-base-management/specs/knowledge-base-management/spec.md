## ADDED Requirements

### Requirement: 授权访问与私有知识库创建
系统 MUST 提供已认证用户可访问的知识库列表及私有库创建入口，ownerId MUST 来自服务端 session。网页写入 MUST 仅允许当前用户私有库，系统库 MUST 为只读。

#### Scenario: 列出可访问知识库
- **WHEN** 用户打开知识库入口
- **THEN** 页面仅列出系统库和自己拥有的私有库，并区分只读与可管理状态

#### Scenario: 创建私有知识库
- **WHEN** 已登录用户提交有效名称创建知识库
- **THEN** 系统绑定该用户为 owner，且拒绝客户端指定其他 owner 或系统 scope

#### Scenario: 拦截未登录与越权请求
- **WHEN** 未登录用户请求管理 API，或用户请求其他人的私有文档、切片、正文及任务
- **THEN** 分别返回 401 或 404，不泄露私有对象的内容或存在性

#### Scenario: 阻止系统库写入
- **WHEN** 普通用户直接调用系统库上传、重处理或删除 API
- **THEN** 系统返回 403，且不创建任务或修改数据

### Requirement: 文档列表与过滤
系统 MUST 提供稳定排序的分页文档列表，支持分类、来源类型、解析状态和文档版本过滤，并独立显示解析、切片及当前模型索引状态。

#### Scenario: 组合过滤与翻页
- **WHEN** 用户选择多个筛选条件并翻页
- **THEN** 系统在授权范围内按全部条件返回结果与分页信息，且更新筛选时回到第一页

#### Scenario: 索引覆盖不完整
- **WHEN** 当前活动切片仅部分具有模型、维度和内容哈希匹配的有效向量
- **THEN** 页面显示部分完成及覆盖数量，不将历史模型向量或无效向量计为完成

#### Scenario: 空态与请求失败
- **WHEN** 列表为空、正在加载或加载失败
- **THEN** 页面分别展示可理解的空态、加载状态或带重试入口的错误提示

### Requirement: 安全上传与原件追踪
系统 MUST 支持单个 PDF、DOCX、DOC、HTML 和 TXT 上传，默认上限 20 MiB，校验实际大小和格式，使用受控存储键保存不可变原件。系统 MUST 保留稳定来源标识、内容哈希和版本；MUST NOT 接受浏览器提供的服务器文件路径作为导入输入。

#### Scenario: 接受文件并排队解析
- **WHEN** owner 上传有效文件
- **THEN** 系统保存原件、原子注册文档和解析任务，返回 202 及可查询标识，不等待完整解析结束

#### Scenario: 重复文件与来源新版本
- **WHEN** 同知识库同来源标识再次上传相同内容，或上传不同内容
- **THEN** 前者返回现有文档及去重提示，后者形成可区分新版本，且并发提交不创建无关重复文档

#### Scenario: 拒绝无效上传
- **WHEN** 文件超限、格式不受支持、格式特征与扩展名不符或存储路径试图越界
- **THEN** 系统明确拒绝，超限返回 413，不留下可处理的文档或任务

### Requirement: 可恢复的文档处理任务
系统 MUST 持久化解析、切片和索引管理任务，由独立 worker 执行并记录排队、运行、成功、失败和所属阶段。每个文档 MUST 至多有一个活动管理任务；任务创建与执行 MUST 校验用户写权限。

#### Scenario: 请求快速结束与状态轮询
- **WHEN** 用户提交耗时处理操作
- **THEN** API 返回任务标识，页面通过轮询更新状态，worker 未运行时保持真实排队状态并提供提示

#### Scenario: 重复和冲突提交
- **WHEN** 文档有活动任务时再次提交相同或不同操作
- **THEN** 相同操作返回已有任务，不同操作返回 409，不同时修改文档产物

#### Scenario: worker 中断恢复
- **WHEN** worker 在任务执行中退出或租约过期
- **THEN** 后续 worker 可有限恢复或标记可重试失败，过期执行者不能发布结果或激活切片，且恢复不产生重复向量

#### Scenario: 依赖缺失与部分失败
- **WHEN** OCR、转换器、语言包或 Embedding 配置不可用，或向量化部分失败
- **THEN** 页面展示对应阶段、有效进度和可操作错误，不把部分失败报告为全部成功，不暴露凭证或服务器堆栈

### Requirement: 内容及切片质量预览
系统 MUST 提供文档详情、按页规范化文本和分页切片预览，展示文档版本、章节、可用页码、切片策略、质量提示和历史切片集。正文 MUST 安全渲染，存储路径 MUST 在服务端受控解析。

#### Scenario: 查看正常与待复核切片
- **WHEN** 用户选择活动或历史切片集，包括质量未通过的切片集
- **THEN** 页面展示有序正文、定位与质量原因，并清楚标识其是否活动

#### Scenario: 产物缺失或路径非法
- **WHEN** 规范化产物不存在、不可读或路径及符号链接超出存储根目录
- **THEN** 返回明确错误，MUST NOT 尝试读取任意其他本地文件

#### Scenario: 预览含脚本的 HTML 来源
- **WHEN** 文档包含 HTML 标记、脚本或远程资源引用
- **THEN** 页面仅呈现安全文本和结构，不执行脚本或自动加载来源中的远程资源

### Requirement: 重处理和版本一致性
系统 MUST 支持 owner 重新解析、重新切片和补齐当前模型索引，复用既有处理策略与幂等标识；失败 MUST 保留先前可用产物，成功发布新规范化内容时 MUST 防止旧切片被视为当前内容。

#### Scenario: 原件不可用于重新解析
- **WHEN** 历史 CLI 文档没有受控原件定位，或受控原件已缺失
- **THEN** 系统提示需重新上传，MUST NOT 根据 sourceUri 读取任意文件或 URL

#### Scenario: 重新解析产生新内容
- **WHEN** 解析成功并且规范化内容哈希发生改变
- **THEN** 系统发布新产物，旧切片集保留历史但不再活动，提示重新切片和索引

#### Scenario: 重新解析失败
- **WHEN** 新解析尝试失败
- **THEN** 系统保留旧可用产物及其切片，页面单独展示本次任务失败原因

#### Scenario: 切片及向量操作幂等
- **WHEN** 用户重用相同切片策略或请求补齐已有有效模型向量
- **THEN** 系统准确提示复用或跳过结果，只处理必要的缺失/失败项，MUST NOT 声称重建已跳过的数据

### Requirement: 文档删除与任务互斥
系统 MUST 在确认后允许 owner 删除私有文档及其切片、向量和文档级任务记录，MUST 明确告知本阶段原件及派生文件保留。删除 MUST NOT 影响其他文档、知识库或 CLI 外部原件。

#### Scenario: 删除无活动任务的私有文档
- **WHEN** owner 确认删除且文档无活动任务
- **THEN** 系统事务删除文档及关联检索数据和文档级任务记录，列表不再显示该文档，其他文档保持不变

#### Scenario: 处理期间删除
- **WHEN** 文档仍存在 pending 或 running 管理任务
- **THEN** 系统返回 409 并说明需要等待任务结束，不部分删除数据

### Requirement: 管理入口与响应式交互
系统 MUST 从聊天界面提供知识库管理入口和返回聊天入口；桌面及移动端 MUST 支持主要浏览、上传与操作流程，使用可访问名称、明确禁用原因和删除确认。

#### Scenario: 移动端查看和操作
- **WHEN** 用户在窄屏打开文档列表和详情
- **THEN** 筛选、任务状态、预览和操作入口可用，不要求依赖桌面侧栏或横向溢出的表格

#### Scenario: 离开处理页面
- **WHEN** 用户离开页面或任务进入终态
- **THEN** 页面停止无用轮询，任务仍由 worker 持久执行，重新打开可恢复显示真实状态
