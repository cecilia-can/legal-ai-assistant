## ADDED Requirements

### Requirement: 会话内生成串行化
系统 SHALL 在任一时刻最多允许同一会话存在一条状态为 `generating` 的生成任务。

该约束 MUST 在服务端和数据库操作边界执行，不得仅依赖浏览器界面禁用。不同会话的生成请求 MUST 可以并行处理。

#### Scenario: 同会话并发请求被拒绝
- **WHEN** 同一会话已有 `generating` 任务时收到不同请求 ID 的新聊天请求
- **THEN** 系统不创建新消息或新任务，并返回可识别的“会话正在生成”响应

#### Scenario: 不同会话允许并行
- **WHEN** 用户向两个不同会话分别提交合法聊天请求
- **THEN** 系统可以分别创建并运行两条生成任务
