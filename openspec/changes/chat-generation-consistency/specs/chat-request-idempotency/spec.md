## ADDED Requirements

### Requirement: 聊天请求幂等创建
系统 SHALL 要求每个聊天生成请求携带非空客户端请求 ID，并以会话 ID 与客户端请求 ID 的组合唯一标识一轮生成。

数据库 MUST 对该组合建立唯一约束。重复提交同一组合时，服务端 MUST 返回已存在的生成任务，且 MUST NOT 创建额外消息或发起额外模型调用。

#### Scenario: 首次提交创建任务
- **WHEN** 客户端以未使用的请求 ID 提交合法聊天请求
- **THEN** 系统创建且仅创建一条对应的生成任务和关联消息

#### Scenario: 网络重试复用任务
- **WHEN** 客户端以相同会话 ID 和请求 ID 重试已提交的请求
- **THEN** 系统返回原生成任务，不创建重复消息且不重复调用模型
