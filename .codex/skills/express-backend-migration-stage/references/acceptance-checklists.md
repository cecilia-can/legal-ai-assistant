# 迁移验收清单

按阶段选择相关部分；清单用于发现遗漏，不替代针对真实改动的测试计划。

## 通用

- 本阶段任务有完成证据，未完成项已记录。
- 没有未批准的范围扩大或无关重构。
- 用户已有改动未被覆盖。
- 测试通过；失败项已区分为本次引入或既有问题。
- API 错误返回约定 JSON，已开始的 SSE 除外。
- 日志不泄露密码、Cookie、令牌、密钥或敏感正文。
- 回滚路径经过验证或有可复现步骤。

## API 契约

- 方法、路径、参数、默认值、状态码及 `{ code, message, data }` 兼容。
- 适用的 400、401、404、409、429、500 有测试。
- `/api` 不返回 Express 默认 HTML 错误页。
- 非法或超大请求体被安全拒绝。

## 数据库与幂等

- Prisma Schema 和 migrations 仍是唯一结构来源。
- 用户数据查询包含所有权条件，多步写入事务正确。
- 可重试 POST 有稳定幂等键和数据库唯一约束，或证明无需重试。
- 重复、并发和响应丢失后的重试不产生重复数据。
- 数据库不可用、等待超时和约束冲突转换为预期错误。

## 认证与安全

- 未登录返回 401，用户不能操作他人资源。
- 不信任浏览器提供的 `userId` 或伪造内部头。
- Cookie 属性符合部署拓扑。
- 登录、退出、过期、OAuth 和账号绑定有测试。
- 检查 CSRF、登录防爆破、开放重定向和密钥泄露。

## SSE 与 AI

- 响应头正确，`token`、`error`、`done` 格式和顺序兼容。
- 客户端停止或断开后，上游会取消。
- 上游超时不会让连接永久悬挂。
- 服务关闭能妥善处理已有流。
- 并发上限生效，超限快速返回 429。
- 半截回复的展示和持久化符合既定策略。

## 部署与容量

- 各环境配置边界清晰，敏感配置安全注入。
- 存活、就绪和优雅关闭正确。
- 代理不缓冲 SSE，数据库连接池与实例数协调。
- 多实例限流共享状态。
- 指标覆盖流量、延迟、错误、429、活动 SSE、数据库连接和 AI 上游。
- 压测报告包含条件、p50/p95/p99、错误率、资源使用和安全容量。

## 前端切换

- 401、404、429、500、非 JSON 和断网表现正确。
- 页面错误提示、重试和关闭保持可用。
- 同源代理或 CORS/Cookie 在目标环境验证通过。
- 回退开关可用且配置来源安全。
