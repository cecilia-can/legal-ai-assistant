# 面试输出文档模板

一次非互动产出完成后，或互动模拟收到“结束模拟 / 生成模拟报告”指令后，写入 `docs/interview-reviews/<YYYY-MM-DD>-<scope-slug>.md`。互动过程不逐轮写文件；用户明确“保存当前进度”时才写入或更新一次检查点。按模式保留相关小节；不要为了套模板生成空小节。

```markdown
# 项目面试复盘：<范围名称>

> 日期：<YYYY-MM-DD>
> 分析范围：<当前实现 / 模块 / 完整项目>
> 岗位：<前端 / AI 全栈 / 混合>
> 场景：<轻量复盘 / 中小厂技术面 / 大厂一面等>

## 证据与边界

- 已阅读：<文件、文档、diff 或测试结果>
- 待确认：<个人职责、指标或其他无法从代码确认的事项；没有则省略>

## 实现概览

<目标、关键模块和调用链。>

## 关键决策与取舍

- <有实现证据支持的决策及原因>

## 面试重点

### <问题标题>

- **面试官提问**：<自然口语化的问题>
- **难度 / 考察意图**：<层级>；<意图>
- **实现证据**：<文件、模块或流程>
- **回答要点**：<结论、实现、取舍与限制>
- **参考回答**：<仅非互动题库模式>
- **追问路径**：<按回答递进的 3–5 条；轻量模式可为 1–2 条>
- **评价与失分点**：<适用时填写>

## 面试风险与待补强

- <可能被追问但证据不足、实现薄弱或需要复习的点>

## 模拟记录

### 第 1 题

- **问题**：<问题>
- **候选人回答**：<互动模式下用户的原话或忠实摘要>
- **面试官评价**：<准确点、缺失点、风险信号与改进建议>
- **后续动作**：<追问 / 切换话题 / 结束>
```
