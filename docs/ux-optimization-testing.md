# Change 1.8 UX 优化 — 手工验收清单

在 `npm run dev` 启动后于 `http://localhost:3000` 逐项验证。

## 1. 骨架屏

| # | 步骤 | 预期 |
|---|------|------|
| 1.1 | 硬刷新首页，观察侧栏 | 会话列表加载时展示「正在加载…」，**不**展示条形骨架 |
| 1.2 | **新建对话** | **直接** EmptyState，**不出现**消息气泡骨架 |
| 1.3 | 切换到**尚未缓存**的已有会话 | 消息区短暂展示气泡骨架，随后展示历史或空态 |
| 1.4 | 加载完成后 | 骨架屏消失，展示真实列表或空状态 |

## 2. 错误与重试

| # | 步骤 | 预期 |
|---|------|------|
| 2.1 | 断开网络或停止 DB 后刷新 | 侧栏展示 InlineError 与「重试」按钮 |
| 2.2 | 点击「重试」 | 再次请求会话列表，按钮显示「重试中…」且 disabled |
| 2.3 | 消息加载失败（无缓存消息） | 消息区 InlineError + 重试 |
| 2.4 | AI 发送失败且已有历史消息 | 主聊天区顶部 banner 展示错误，可「关闭」或「重试」 |

## 3. 键盘快捷键（对齐 ChatGPT）

| # | 快捷键 | 预期 |
|---|--------|------|
| 3.1 | Ctrl/Cmd + **Shift + O** | 新建会话（**不会**打开浏览器新标签） |
| 3.2 | **Shift + Esc** | 聚焦聊天输入框 |
| 3.3 | Esc（移动端抽屉打开，无 Shift） | 关闭会话抽屉 |
| 3.4 | Esc | **不**删除/终止当前会话 |
| 3.5 | Ctrl/Cmd + .（流式中） | 停止当前流式生成 |

## 4. 输入区图标按钮

| # | 步骤 | 预期 |
|---|------|------|
| 4.1 | 输入非空 | 圆形 **向上箭头** 发送按钮可用 |
| 4.2 | 流式且输入为空 | **外圆内方块** 停止按钮 |
| 4.3 | 流式且输入非空 | 显示发送箭头（非停止） |
| 4.4 | 仅图标 | 具备 `aria-label`「发送」「停止生成」 |

## 5. 流式与滚动

| # | 步骤 | 预期 |
|---|------|------|
| 5.1 | 发送消息触发 AI 流式 | Header subtitle 旁 pulse 圆点 |
| 5.2 | 流式结束 | pulse 消失 |
| 5.3 | 在底部附近时流式 | 列表自动跟随到底部 |
| 5.4 | 向上滚动后流式继续 | 显示「回到底部」按钮 |

## 6. 移动端（DevTools 375px）

| # | 步骤 | 预期 |
|---|------|------|
| 6.1 | 打开会话抽屉后按 Esc | 抽屉关闭 |
| 6.2 | 聚焦输入框 | 字号 ≥16px |
| 6.3 | 长消息列表 | 输入区固定在底部可见 |

## 7. 构建

```bash
npm run lint
npm run build
```

均应通过。
